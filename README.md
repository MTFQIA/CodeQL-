# Agent + CodeQL CVE Root-Cause Localization Experiment

本仓库保存 mini-swe-agent 与 CodeQL 结合进行真实 CVE 根因定位实验的 A、B、C 三轮完整实验结果。

## 实验环境

- Agent：mini-swe-agent 2.4.6
- Model：DeepSeek-v4-Flash
- CodeQL：2.26.1
- 漏洞目标数量：5
- 每个目标最多进行 3 轮自定义 CodeQL 查询

## 实验目标

实验主要验证两个问题：

1. Agent 在没有明确漏洞提示时，是否具备自主分析源码并定位漏洞根因的能力。
2. 随着 CVE 编号、漏洞类型和根因描述等先验信息逐步增加，Agent 的根因定位成功率和执行效率是否会提高。

## A 轮

只向 Agent 提供漏洞版本源码。

不提供：

- CVE 编号
- 漏洞类型
- 根因描述
- 关键文件
- 关键函数
- 精确代码位置
- 人工 CodeQL 查询

主要用于考察 Agent 的自主漏洞分析能力。

## B 轮

向 Agent 提供：

- 漏洞版本源码
- CVE 编号
- 漏洞类型

但仍不提供具体文件、函数、代码位置和自然语言根因描述。

## C 轮

在 B 轮基础上进一步提供自然语言形式的漏洞根因描述。

仍不提供：

- 具体漏洞文件
- 关键函数
- 精确代码行
- 人工编写的 CodeQL 查询

## A/B/C 总体结果

| 指标 | A轮 | B轮 | C轮 |
| --- | ---: | ---: | ---: |
| 根因命中率 | 80% | 100% | 100% |
| 平均查询轮数 | 1.8 | 1.4 | 1.6 |
| 平均最终告警数 | 3.6 | 3.6 | 2.2 |
| 根因告警占比 | 38.9% | 50.0% | 63.6% |
| 平均 Agent 步数 | 99.6 | 69.2 | 60.2 |
| 平均 Token | 8.45M | 4.38M | 3.16M |
| 平均耗时 | 77.45 min | 45.81 min | 31.89 min |

## 测试漏洞

- CVE-2016-4074 — jq — 不受控递归 / 资源耗尽
- CVE-2021-3156 — sudo — 堆缓冲区溢出
- CVE-2021-4034 — pkexec — 越界读取 / 越界写入
- CVE-2022-0847 — Dirty Pipe — 对象状态初始化不当
- CVE-2024-6387 — OpenSSH — 异步信号处理竞态

## 仓库目录

rounds/A 保存 A-round-final 的完整解压内容。

rounds/B 保存 B-round-final 的完整解压内容。

rounds/C 保存 C-round-final 的完整解压内容。

repo-info 保存仓库整理过程、文件数量和大文件检查结果。

ORIGINAL_ARCHIVES.sha256 保存原始三个 round-final 压缩包的 SHA256 校验值。

## 实验流程

每个实验目标大致按照以下流程进行：

源码分析
→ 项目构建
→ 创建 CodeQL 数据库
→ 运行标准查询套件
→ 分析 baseline
→ Agent 生成自定义 QL
→ 执行查询
→ 隐藏评价器判断根因命中
→ 必要时继续迭代
→ 保存最终结果

## 结论

实验结果表明，Agent 在没有明确漏洞提示的情况下已经具备一定的自主漏洞分析和根因定位能力。

随着 CVE 编号、漏洞类型以及自然语言根因描述逐步加入，根因定位稳定性提高，同时 Agent 的步骤数、Token 消耗和总体分析时间呈下降趋势。

不同漏洞对先验信息的受益程度并不完全一致，因此实验结果主要说明增加漏洞语义信息能够总体减少 Agent 的无效探索，并提高根因定位效率。
